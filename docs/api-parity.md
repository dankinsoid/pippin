## Missing, classified

One verdict per `clojure.core` name this core lacks, from `scripts/api-missing.edn`, by the rule of design §3 «Предел расхождения — ClojureScript». `make api-diff` fails on a missing name without a verdict and on a verdict for a name that is present again, so a name cannot slide through unclassified.

The cljs column is the evidence, not the verdict. A name cljs keeps obliges us to code or to a reason of our own; a name cljs dropped is evidence for a §8 row whose reason must still be ours (`agent`, `send`, `await`, `future`, `pmap`, `ref`, `dosync` are absent there because JS has one thread, which is no argument here); a name cljs repointed at its host is leave to repoint at ours.
