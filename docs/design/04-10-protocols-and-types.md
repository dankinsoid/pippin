### Протоколы и типы — свои, в обоих режимах
- `defprotocol`/`deftype`/`reify`/`extend-type` — своя таблица диспатча (как в CLJS/ClojureDart), не хостовые типы. Компилятор может опустить `deftype` в struct с vtable — это представление, не семантика.
- `extend-type` на Swift-типы работает (диспатч по метаданным типа), новый тип не нужен.
- **`reify` — четыре случая:**
  1. Clojure-протокол → таблица, бесплатно.
  2. `@objc`-протокол/класс → живой класс из ObjC-рантайма (делегаты, `UIView`-подклассы — всё UIKit). Полностью динамически, из REPL.
  3. Swift-only протокол → **отложен (решено 2026-09-27)**, из ближнего плана уходит. Две причины. **Ложное тождество:** `defprotocol`/`deftype` — намеренно своя таблица диспатча, а не хостовые типы (пункт выше говорит это прямо); если `reify` начнёт ещё и производить Swift-конформности, одна форма понесёт две несовместимые семантики — Clojure-случай бесплатный и динамический, Swift-случай требует предкомпилированного адаптера, которого до запуска программы может и не быть. Пункт ниже уже запрещает ровно такое расхождение («то, за что SCI платит годами»). Вторая: адаптеру нужен шаг сборки, поэтому из REPL он недостижим в принципе. Чем это закрывается, честно, а не как бесплатный выигрыш: свои конформности (`Comparable`, `Codable`, `Hashable` над `Value`) пишем один раз сами, и пользовательской формой они не являются; **протокол с одним методом — это замыкание**, и его стоит взять дешёвым сгенерированным адаптером над Clojure-fn — этим накрыто делегатоподобное большинство; протокол из **чужой** Swift-библиотеки, которому нужен пользовательский тип, стоит десяток строк рукописного Swift — узко, но не пусто, и сказать это надо заранее, а не обнаружить. Тот же ответ даёт React Native (напиши нативный модуль), та же конвенция устоялась у Rust в `-sys`-крейтах.
  4. Подкласс Swift-only класса с vtable → только заранее сгенерированный `open class` прокси. Честно закрыто; в Apple-фреймворках таких классов мало.
- **Не** генерировать честные конформности из `deftype` в компиляторе — расхождение семантик между режимами (то, за что SCI платит годами). Адаптер — единый контракт; компилятор может его инлайнить.
