### Swift → Clojure
- **`Value`** — один тип на границе: struct над raw-указателем, RC в `init`/`deinit`, конвертеры примитивов, литералы, `Optional` → nil, `callAsFunction`. Вызов `clj.fn("app/handle")(args)` → `clj_invoke` по C ABI.
- **Структуры — shape-мапа напрямую, рефлексия фолбэком:** для типа, чей список полей генератор видел на сборке, печатается прямое построение shape-мапы — интернированный shape в статике, значения inline по индексу; обратно — сверка указателя shape с ожидаемым, попадание даёт чтение полей по индексу без хеширования, промах уходит на общий путь (guard инлайн-кэша, только на границе). Для типов, которых генератор не видел, — рефлексия с кэшем `typeInfo` по типу («Генератор стабов»): конформанса не требует и умеет конструировать. `CLJEncoder`/`CLJDecoder` (как JSONEncoder, но результат — персистентная мапа с keyword-ключами) слот фолбэка потеряли по своей цене: список полей известен Swift на компиляции, но через экзистенциальный `KeyedEncodingContainer` переоткрывается на каждом экземпляре — witness table на поле, контейнер на уровень вложенности, `CodingKey` → строка в таблицу кейвордов. Порог, ниже которого генератор зовёт общий путь вместо печатаемого, берётся из бенча (§10 шаг 4), не на глаз.
- **Без копирования — host-value:** `UIView`, `DateFormatter`, дорогие структуры — opaque объект, `(:field obj)` по метаданным по требованию, `ILookup`; первый `assoc` материализует в настоящую мапу.
- **Владение:** `Value` в Swift = +1; deinit может прийти в любом потоке → экспортированный объект переходит на атомарный счётчик (biased RC). Swift-объекты у нас — `Unmanaged` retain.
- **Ошибки — свои:** `ex-type` чужой ошибки — её динамический тип, поэтому она ловится и группируется как наша без всякого реестра; `CancellationError` — это `:cancelled` в обе стороны (§4, «Тип ошибки»). Реестр нужен `ex-data`, не опознанию: опознание — динамический каст по метатипу, а не имя (§4).
- **Замыкания в обе стороны** с первого дня.
